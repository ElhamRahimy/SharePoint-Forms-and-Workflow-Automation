### Project Request Registration & Executive Approval Interface

Developed a customized SharePoint-based interface for registering, reviewing, and managing IT project requests across multiple companies and departments.

The form included structured sections for:

- **Request Information:** Project request title, requesting company, subsidiary, requester, and request description.
- **Project Planning:** Execution priority, project size, responsible department, project manager, project stakeholders, and estimated start and end dates.
- **Proposed vs. Executive-Approved Information:** Separate fields for initially proposed project details and information approved by the CEO.
- **Project Documentation:** Uploading and managing project order documents, preliminary analysis documents, and Functional Requirements Documents (FRD).
- **Workflow Navigation:** Dedicated tabs for project registration, request history, workflow history, and open tasks.
- **Project Classification:** Identifying project types and maintaining project reference information.

- ### Project Technical Document Search & Retrieval

Designed and developed a centralized document search and retrieval interface within the IT Project Lifecycle Management (PLC) system.

The interface enabled **Project Managers, Product Owners, and PMO specialists** to locate IT projects and access their associated technical and project management documentation.

**Key Capabilities:**

- Searching for IT projects by project title and organizational unit.
- Displaying matching projects with their assigned project managers and executing departments.
- Selecting a project to retrieve its associated documentation.
- Displaying document names, document types, last modification dates, and last editors.
- Supporting the retrieval of project-related documents, including project order documents and project planning documentation.
- Providing paginated search results for projects and documents.

**Business Value:**

The functionality centralized access to project documentation, improved information retrieval, and supported collaboration between project managers, product owners, and PMO teams.

It reduced the need to manually locate documents across separate project records and provided a structured interface for accessing relevant technical and project management information.

The interface supported structured project initiation, executive review, document management, and workflow tracking within a centralized enterprise platform.
